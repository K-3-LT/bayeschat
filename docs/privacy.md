# Privacy

This file is a pointer. The policy itself is maintained in one place, so there is
never a stale copy to compare against:

**Canonical policy: <https://bayeschat.xyz/privacy.html>** (last updated 9 June 2026)

## What the policy commits to

- BayesChat runs no server of its own. Nothing is collected, stored or transmitted to us.
- API keys and MCP credentials live in the keychain on your device.
- Conversations, presets and memories are stored locally on your device.
- Your messages go only to the AI provider you configured, or to the MCP servers you
  added — nowhere else.
- Memory is opt-in, listed in Settings, and can be edited or deleted item by item.

## Why this file exists

The App Store listing asks for a privacy policy URL and points at the canonical page
above. This file exists so anyone reading the repository can find that link without
leaving GitHub — not as a second, divergent copy of the text.
